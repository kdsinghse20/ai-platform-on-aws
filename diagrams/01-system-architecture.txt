================================================================================
                              DATA FLOW SUMMARY
================================================================================

REQUEST FLOW (User to Models):
  1. User → HTTPS to ALB (encrypted)
  2. ALB → Terminates TLS/SSL
  3. ALB → HTTP to NGINX (internal, private)
  4. NGINX → Reverse proxy to OpenWebUI:8080
  5. OpenWebUI → HTTP to Ollama:11434 (private network)
  6. Ollama → Queries AI Models
  7. Response → Back through reverse flow

RESPONSE FLOW (Models to User):
  1. Ollama → JSON response to OpenWebUI
  2. OpenWebUI → HTML response to NGINX
  3. NGINX → HTTP response to ALB
  4. ALB → Encrypts with TLS
  5. ALB → HTTPS response to User

================================================================================
                           SECURITY CHARACTERISTICS
================================================================================

✅ IMPLEMENTED:
  • All compute instances in PRIVATE subnets (no public IPs)
  • Only ALB exposed to internet
  • Security group-based firewall rules
  • HTTPS for all external communication
  • Private network for internal communication
  • IAM least privilege (SSM access)
  • No SSH key exposure
  • Multi-AZ redundancy
  • Health checks for high availability
  • TLS 1.2+ encryption

KEY SECURITY FEATURES:
  • OpenWebUI ← Only accessible from ALB (security group)
  • Ollama ← Only accessible from OpenWebUI (security group)
  • Internet ← Only port 80 (redirect) and 443 (HTTPS) open
  • NAT Gateways ← Outbound internet for model downloads
  • Database/State ← None in this setup (stateless design)

PHASE 2 - CONFIGURATION (Ansible):
  Common Role → System setup
        ↓
  Ollama Role → Install AI runtime
        ↓
  OpenWebUI Role → Install web UI
        ↓
  NGINX Role → Configure reverse proxy
        ↓
  ✓ Services Ready

PHASE 3 - VERIFICATION:
  Test Ollama API → curl http://localhost:11434/api/tags
  Test OpenWebUI → curl http://localhost:8080
  Test NGINX → nginx -t && systemctl status nginx

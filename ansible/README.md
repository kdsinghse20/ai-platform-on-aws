# Ansible Configuration Management - AI Platform

Complete configuration management for deploying and configuring AI Platform services on EC2 instances.

---

## Overview

This directory contains Ansible playbooks and roles for configuring services on AWS EC2 instances. After Terraform provisions the infrastructure, Ansible automates the installation and configuration of:

- **Ollama**: AI model runtime
- **OpenWebUI**: Web interface for Ollama
- **NGINX**: Reverse proxy
- **Common**: System dependencies and OS-level setup

### Key Features

- ✅ **Role-Based**: Modular roles for each service
- ✅ **Idempotent**: Safe to run multiple times
- ✅ **Templated**: Dynamic configuration files
- ✅ **No SSH Required**: Works with AWS Systems Manager
- ✅ **Automated**: Single playbook deploys all services
- ✅ **Model Management**: Automatic model downloading

## Playbook Overview & Execution Order

### **site.yml** - Main Orchestration

```yaml
---
- import_playbook: common.yml       # Step 1: System setup
- import_playbook: ollama.yml       # Step 2: AI runtime
- import_playbook: openwebui.yml    # Step 3: Web UI
# - import_playbook: nginx.yml      # Step 4: Reverse proxy (optional)
```

**Execution Flow**:

```
1. common.yml
   ├─ Update system packages
   ├─ Install system dependencies
   ├─ Configure firewall rules
   ├─ Setup Docker (if needed)
   └─ Install Python tools

2. ollama.yml
   ├─ Install Ollama runtime
   ├─ Configure Ollama service
   ├─ Start Ollama service
   └─ Download AI models

3. openwebui.yml
   ├─ Install OpenWebUI
   ├─ Configure OpenWebUI
   ├─ Connect to Ollama
   └─ Start OpenWebUI service

4. nginx.yml (optional)
   ├─ Install NGINX
   ├─ Configure NGINX reverse proxy
   ├─ Setup TLS certificates
   └─ Start NGINX service
```

## Role Overview & Dependencies

### **1. Common Role** (`roles/common/`)

**Purpose**: System-level setup and dependencies.

**Tasks Performed**:
- System package updates (`apt update`, `apt upgrade`)
- Install core dependencies (curl, wget, git, vim)
- Install Python 3 and pip
- Configure sudoers for passwordless execution
- Setup SSH keys (if needed)
- Install monitoring tools
- Configure logging

**Hosts**: ALL
**Run Order**: FIRST (required by all other roles)
**Handlers**: System service restarts

**Details**: [Common Role README](roles/common/README.md)

---

### **2. Ollama Role** (`roles/ollama/`)

**Purpose**: Install and configure Ollama AI runtime.

**Sub-Tasks**:

#### **install.yml** - Installation
- Download Ollama binary
- Install to /usr/bin/ollama
- Create Ollama system user
- Setup directory structure

#### **configure.yml** - Configuration
- Create systemd service file
- Set environment variables (GPU support, memory limits)
- Configure logging
- Setup permission management

#### **models.yml** - Model Management
- Pull Gemma 3 model
- Pull Llama 3.2 model
- Verify model integrity
- Setup model caching

#### **verify.yml** - Verification
- Check Ollama service status
- Test API connectivity
- Verify models are loaded
- Validate model responses

**Hosts**: ollama group
**Port**: 11434 (HTTP API)
**Dependency**: 🔗 common role

**Environment Variables**:
```bash
OLLAMA_HOST=0.0.0.0:11434    # Bind to all interfaces
OLLAMA_MODELS=/var/lib/ollama/models
OLLAMA_NUM_PARALLEL=1        # Model parallelism
OLLAMA_NUM_THREAD=4          # CPU threads
```

**Models Downloaded**:
- `gemma:3` - Google's Gemma 3 model
- `llama2:latest` - Meta's Llama 3.2 model

**Details**: [Ollama Role README](roles/ollama/README.md)

---

### **3. OpenWebUI Role** (`roles/openwebui/`)

**Purpose**: Install and configure OpenWebUI web interface.

**Sub-Tasks**:

#### **install.yml** - Installation
- Install Docker (if not already installed)
- Install Docker Compose
- Create OpenWebUI directories
- Setup network volumes

#### **configure.yml** - Configuration
- Create docker-compose file
- Configure environment variables
- Setup volume mounts
- Configure networking

#### **models.yml** - Model Connection
- Configure Ollama API endpoint
- Setup model discovery
- Configure WebUI settings

#### **verify.yml** - Verification
- Check service health
- Verify Docker containers running
- Test web interface accessibility
- Validate Ollama connection

**Hosts**: openwebui group
**Port**: 8080 (Web UI, behind NGINX)
**Dependency**: 🔗 common role, ollama running

**Docker Configuration**:
```yaml
services:
  open-webui:
    image: ghcr.io/open-webui/open-webui:latest
    ports:
      - "8080:8080"
    environment:
      - OLLAMA_BASE_URL=http://ollama:11434
      - WEBUI_AUTH=false  # Development setting
    volumes:
      - ./data:/app/backend/data
```

**Details**: [OpenWebUI Role README](roles/openwebui/README.md)

---

### **4. NGINX Role** (`roles/nginx/`)

**Purpose**: Configure NGINX as reverse proxy.

**Sub-Tasks**:

#### **install.yml** - Installation
- Install NGINX from apt/package manager
- Verify installation
- Setup systemd service

#### **configure.yml** - Main Configuration
- Create proxy configuration
- Setup upstream blocks for OpenWebUI
- Configure SSL/TLS (if certificates provided)
- Setup security headers

#### **ssl.yml** - SSL/TLS Setup
- Install certificates
- Configure HTTPS listeners
- Setup HTTP → HTTPS redirect
- Configure certificate renewal (Let's Encrypt)

#### **verify.yml** - Verification
- Test NGINX configuration syntax
- Verify service is running
- Test connectivity to backends
- Check SSL certificate validity

**Hosts**: openwebui group (NGINX runs on same instance)
**Ports**: 80 (HTTP), 443 (HTTPS)
**Dependency**: 🔗 common role, openwebui running

**Configuration**:
```nginx
upstream openwebui {
    server 127.0.0.1:8080;
}

server {
    listen 80;
    server_name _;
    
    location / {
        proxy_pass http://openwebui;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

**Details**: [NGINX Role README](roles/nginx/README.md)

## Quick Start

### **Prerequisites**

1. **Terraform Deployment Complete**
   ```bash
   cd terraform/environments/dev
   terraform apply  # Creates infrastructure
   ```

2. **Generate Ansible Inventory**
   ```bash
   terraform output -raw ansible_inventory > ../../../ansible/inventory/hosts.yml
   ```

3. **Verify Connectivity**
   ```bash
   cd ansible
   ansible all -m ping -i inventory/hosts.yml
   ```

### **Step 1: Install Ansible**

```bash
# Python 3 + pip required
python3 -m pip install ansible==2.10+
ansible --version
```

### **Step 2: Verify Inventory**

```bash
# List all hosts
ansible-inventory -i inventory/hosts.yml --list

# Test connectivity
ansible all -i inventory/hosts.yml -m ping
```

### **Step 3: Run Playbooks**

```bash
# Option 1: Run all playbooks (recommended)
ansible-playbook playbooks/site.yml -i inventory/hosts.yml

# Option 2: Run individual playbooks
ansible-playbook playbooks/common.yml -i inventory/hosts.yml
ansible-playbook playbooks/ollama.yml -i inventory/hosts.yml
ansible-playbook playbooks/openwebui.yml -i inventory/hosts.yml
# ansible-playbook playbooks/nginx.yml -i inventory/hosts.yml
```

### **Step 4: Verify Deployment**

```bash
# Check Ollama
ansible ollama -i inventory/hosts.yml -m shell -a "curl -s http://localhost:11434/api/tags"

# Check OpenWebUI
ansible openwebui -i inventory/hosts.yml -m shell -a "curl -s http://localhost:8080"

# Check NGINX
ansible openwebui -i inventory/hosts.yml -m shell -a "nginx -t"
```

ssh -i ~/.ssh/your-key.pem ubuntu@10.0.20.x

## Troubleshooting

### **Connectivity Issues**

```bash
# Test SSH/SSM connection
ansible all -i inventory/hosts.yml -m ping

# Verbose connection debug
ansible all -i inventory/hosts.yml -m ping -vvv

# Check Ansible config
ansible-config dump
```

### **Role Failures**

```bash
# Run with verbose output
ansible-playbook playbooks/ollama.yml -vvv

# Check task output
# Look for: "FAILED" lines with error messages
# Common issues:
# - Network connectivity
# - Insufficient disk space
# - Package conflicts
```

### **Service Not Running**

```bash
# SSH into instance (via SSM)
aws ssm start-session --target i-xxxxxxxxx

# Check service status
systemctl status ollama
systemctl status openwebui
systemctl status nginx

# View logs
journalctl -u ollama -n 50
journalctl -u openwebui -n 50
journalctl -u nginx -n 50
```

### **Model Download Issues**

```bash
# SSH into Ollama instance
# Check disk space
df -h

# Check Ollama logs
journalctl -u ollama -f

# Manual model pull
curl -X POST http://localhost:11434/api/pull -d '{"name": "gemma:3"}'
```

  - mistral:latest

### **Conditional Tasks**

```yaml
- name: Install GPU drivers
  when: ansible_fact.system == 'Linux' and gpu_enabled | bool
  block:
    - name: Install NVIDIA drivers
      apt:
        name: nvidia-driver-535
        state: present
```

### **Handler Management**

```yaml
handlers:
  - name: Restart Ollama
    systemd:
      name: ollama
      state: restarted
      daemon_reload: yes
```
